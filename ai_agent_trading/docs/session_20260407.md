## 4. `src/v12/live_engine_v2.py` 버그 수정

### 4-1. Leg B abort 메시지 오해 유발 버그 수정 (line ~683)

**문제**: `entry_premium`과 `current_premium`의 부호 기준이 달라서 DC 방향 abort 시 오해 발생
- `entry_premium` = (USDT - USDC) / USDC → DC에서 **음수**
- `current_premium` = (Leg-B-sell - Leg-A-buy) / Leg-A-buy → 양수=수익, 음수=손실

**수정**: abort 텔레그램 메시지에 방향(DT/DC), 진입예상수익(abs), 현재수익성, 상태 구분 추가
```python
# 수정 후 메시지 형식
f"⚡ Leg B 조기 청산 (스프레드 역전 or 수익성 소멸)\n"
f"방향: {direction}  |  진입예상수익: +{entry_margin:.4%}\n"
f"현재 수익성: {current_premium:+.4%}  (필요 최소: +{fee_stack:.4%})\n"
f"※ 스프레드 완전 역전 — 손절 청산  (or 수익 마진 부족 — 예방 청산)\n"
```

> **참고**: abort 로직 자체는 맞음. `current_premium < fee_stack` 조건은 양방향 모두 올바름.
> DC에서 current_premium이 음수면 스프레드 완전 역전 → 정상 손절.
