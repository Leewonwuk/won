# PRD: Go-Running (고라니 달리기)

## 목표
유해조수로 낙인 찍혀 안락사 위기에 처한 고라니가 마취에서 깨어나 고향 숲 "수프리"로 달려가는 사이드스크롤 러너 게임.

## 사용자
PC 브라우저 사용자 (한국어 인터페이스)

## 스토리
고라니는 도시에 내려왔다가 동물협회에 발각되어 마취총을 맞고 안락사 직전이다.
정신이 번쩍 든 고라니는 수프리(고향 숲)를 향해 도망친다.
도시에는 환경호르몬(음식 쓰레기, 스테로이드 주사)이 넘쳐나고,
맞으면 털이 부스스해진다.
낮에는 도시의 참새들이, 밤에는 쥐들이 고라니를 도와준다.
중간 보스를 처치하며 수프리를 향해 계속 달린다.

## 핵심 기능 (MVP)

### 1. 인트로 화면
- 스토리 텍스트 순차 출력 (타이핑 효과)
- "달려라!" 버튼으로 게임 시작
- 레트로 칩튠 BGM 재생 시작

### 2. 메인 게임 루프
- 무한 사이드스크롤 배경 (도시 → 교외 → 숲 순환)
- 고라니 달리기 애니메이션 (gorani-normal.gif)
- 점프 (스페이스바 / 화면 탭): 단일 점프
- 거리(점수) 카운터

### 3. 장애물 & 아이템
- 장애물: 환경호르몬 (쓰레기통, 스테로이드 주사기) — 피격 시 HP -1, gorani-hurt.gif로 전환
- 아이템: 도토리(점수 +100), 나뭇잎(HP 회복)
- HP 3칸 (하트)

### 4. 낮/밤 시스템
- 60초 주기로 낮↔밤 전환
- 낮: 참새 도우미 등장 (장애물 제거)
- 밤: 쥐 도우미 등장 (아이템 추가 수집)
- 배경색 / 오버레이로 낮밤 표현

### 5. 중간 보스
- 500m마다 보스 등장
- 보스: 방역복 입은 동물협회 직원 (마취총 발사)
- 점프로 피하거나 도우미 동물이 처치
- 처치 시 점수 보너스

### 6. 레트로 BGM & SFX
- BGM: Tone.js 칩튠 (낮/밤/보스 각각 다른 테마)
- SFX: 점프음, 아이템 수집음, 피격음, 보스등장음

### 7. 게임오버 화면
- "고라니가 잡혔다..." 텍스트
- 최종 거리 및 점수 표시
- 다시 도전 버튼

## MVP 제외 사항
- 모바일 터치 최적화 (추후 추가)
- 온라인 랭킹/리더보드
- 저장 기능 (로컬스토리지는 가능)
- 배경음악 파일 (Tone.js 생성으로 대체)
- 추가 챕터/맵 (수프리 도착 엔딩은 MVP 제외)
