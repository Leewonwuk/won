# Architecture Decision Records: Go-Running

## 철학
빠른 브라우저 실행 우선. 빌드 도구 없이 CDN만으로 즉시 실행 가능한 최소 구현 선택.

---

### ADR-001: 게임 엔진 — Phaser 3
**결정**: Phaser 3 (CDN v3.60+) 사용
**이유**: 브라우저 게임 표준 라이브러리이며 Arcade Physics 내장. 빌드 없이 CDN만으로 동작.
**트레이드오프**: Three.js 대비 3D 불가. 하지만 2D 러너 게임에는 과분한 기능이 있어 충분.

---

### ADR-002: 주인공 렌더링 — 픽셀 스프라이트 상태머신
**결정**: GIF/DOM 오버레이를 제거하고 Phaser 픽셀 텍스처 + 상태머신으로 전환.
**이유**: 충돌/연출/카메라 효과와 렌더 파이프라인을 일치시켜 게임 조작감을 높이기 위함.
**트레이드오프**: 실제 이미지 기반 캐릭터보다 디테일이 단순함. 대신 런타임 성능과 제어성이 좋아짐.
**구현**: `BootScene`에서 `gorani-*` 텍스처/애니메이션 생성, `Gorani.js`에서 run/jump/hurt 상태 전환.

---

### ADR-003: 오디오 — Tone.js (외부 오디오 파일 없음)
**결정**: Tone.js (CDN)로 레트로 칩튠 BGM/SFX를 코드로 생성
**이유**: 외부 오디오 파일 다운로드 없이 게임에 레트로 8비트 BGM 구현 가능. 낮/밤/보스 테마를 각각 다른 시퀀스로 코드 정의.
**트레이드오프**: 실제 작곡된 음악 대비 단순할 수 있음. 하지만 레트로 감성에 오히려 적합.

---

### ADR-004: 빌드 도구 없음
**결정**: Webpack/Vite/Babel 없이 ES6 모듈 + CDN만 사용. `npx serve src -l 3000`으로 서빙.
**이유**: 최소 의존성으로 즉시 실행 가능. 설정 복잡도 제거. 하네스 step 실행 시 빌드 과정 불필요.
**트레이드오프**: 브라우저 ES6 모듈 지원 필요 (최신 Chrome/Firefox는 모두 지원). IE 미지원.

---

### ADR-005: 폰트 — Press Start 2P (Google Fonts)
**결정**: Google Fonts CDN에서 'Press Start 2P' 폰트 로드
**이유**: 레트로 픽셀 감성에 맞는 무료 폰트. CDN으로 설치 없이 사용 가능.
**트레이드오프**: 한글 미지원. 게임 내 UI 텍스트는 영어/숫자 위주로 구성. 스토리 텍스트는 기본 한글 폰트 fallback 사용.

---

### ADR-006: 충돌 안정성 — 상태 플래그 기반 판정
**결정**: 수집/피격 객체에 상태 플래그(`collected`, `hit`)를 도입해 재충돌을 차단.
**이유**: overlap 프레임 중복 처리로 인한 미수집/다중판정 문제를 제거하기 위함.
**트레이드오프**: 객체 클래스에 상태 관리 코드가 증가.
**구현**: `Item.collect()`에서 바디 비활성화 후 페이드아웃 제거, `Obstacle.markHit()`에서 즉시 충돌 비활성화.

---

### ADR-007: 보스 패턴 분리 — 경고 배너 + 다트 스케일링
**결정**: 보스 등장 시 경고 배너를 노출하고, 다트 속도를 현재 scrollSpeed 기반으로 스케일링.
**이유**: 일반 구간/보스 구간의 체감 구분과 난이도 일관성을 확보.
**트레이드오프**: 보스 구간 난도가 이전보다 상승함.
