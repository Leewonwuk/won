### Failure Mode (Pre-Mortem — 7 트랙 착수 전 검토 필수)
1. **필터 블러링**: `pixelArt:true` 있어도 일부 Android GPU 가 zoom 시 bilinear 끼움. → 7-D 정수 배율 규약 필수.
2. **UI-월드 카메라 꼬임**: HUD 가 월드 카메라 좌표로 그려지면 zoom 시 글자까지 커짐. → 7-C 에서 UI 카메라 분리 + `ignore()` 필수.
3. **모바일 성능**: 환자·티켓 30+개 + 실시간 depth sort → 저가 Android GPU 스톨. 카이로 방식=타일 베이킹 + 정적 depth. → `renderTexture` 로 정적 배경(그리드·고정 시설) 합성 권장.
4. **핀치-배치 제스처 충돌**: 한 손가락 touch 를 "배치 시작" 으로 처리하면 두 번째 손가락 직후 배치가 즉시 실행돼 오배치. → 7-E 150ms 지연 + 두 번째 포인터 감지 시 취소 규약.
