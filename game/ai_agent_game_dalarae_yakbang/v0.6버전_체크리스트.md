# 달아래약방 — 구현 체크리스트 (확정판)

> Claude Code는 Phase 1부터 순서대로 구현한다.  
> 각 Phase 완료 후 다음 Phase로 진행할 것.  
> `[ ]` 체크 완료 시 `[x]`로 변경.

---

## Phase 1 — 기반 시스템

- [ ] **10×10 그리드 렌더링**
  - 1×1 타일 단위
  - 대문은 맵 하단 중앙 고정
  - 타일 클릭으로 건물 배치/철거

- [ ] **대문 PNG 배치 및 환자 스폰 포인트 연결**
  - 스폰 포인트 = 대문 바로 위 타일
  - 환자 퇴장도 동일 포인트

- [ ] **마루 설치 및 통행 경로 탐색 로직**
  - 환자는 마루 타일로만 이동
  - 마루 미연결 시 해당 시설 접근 불가 (시설 존재해도 무시)

- [ ] **UI 레이아웃**
  - 좌상단: 시간
  - 우상단: 돈 · 명의
  - 우하단: 메뉴탭

- [ ] **메뉴탭 구조**
  - 카테고리: 치료방 / 치료인 / 음식점 / 가게 / 부대시설 / 조경
  - 해금 전 시설은 탭에서 보이지 않음. 해금 후 표시.

- [ ] **초기 상태 세팅**
  - 잔액: 100전
  - 해금 상태: 뜸방 · 마루만 해금
  - 무수리 1명 무료 지급
  - 추가 무수리 구매가: 10전

- [ ] **시간 시스템**
  - 15초 = 1주 / 1분 = 1달 / 12분 = 1년
  - 좌상단 시계 UI 연동

## Phase 2 — 환자 이동·체류 로직

- [ ] **자동 스폰**
  - 10초마다 노비 환자 1명 출현
  - 수요 비율: 뜸 60% / 침 30% / 약 10% 무작위

- [ ] **스폰 딜레이**
  - 직전 환자 스폰 후 다음 스폰까지 최소 3초 딜레이
  - 자동 · 가중치 · 편의 모든 스폰에 동일 적용

- [ ] **환자 체류시간 타이머**
  - 기본 체류시간: 15초
  - 해우소 이용 시 +5초 / 우물 이용 시 +5초 (누적, 상한 없음)

- [ ] **퇴장 트리거 3가지**
  - ① 시간 만료: 시설 이용 중이면 이용 완료 후 퇴장
  - ② 돈 소진: 즉시 퇴장 (시설 이용 중이어도 즉시)
  - ③ 모든 시설 이용 완료: 즉시 대문으로 퇴장

- [ ] **환자 시설 이용 우선순위**
  1. 수요에 맞는 치료방 1회 이용
  2. 미이용 편의시설 1회 이용
  3. 남은 시간·돈 허용 시 미이용 치료방·편의시설 반복
  - 모든 시설 환자당 1회 이용 제한

- [ ] **시설별 이용 소요시간**
  - 치료방 (뜸·침·약): 4초
  - 해우소 · 우물: 2초

- [ ] **계층별 소지금**
  - 노비 5전 / 농민 10전 / 상인 15전 / 선비 20전 / 양반 30전

- [ ] **퇴장 시 대문 복귀 로직**

## Phase 3 — 시설 해금·직원 시스템

- [ ] **해금 조건 체인 (전부 "이용" 기준)**
  - 뜸 이용 5명 → 해우소 해금
  - 뜸 이용 10명 → 침방 해금
  - 침 이용 20명 → 약방 해금
  - 해우소 이용 10명 → 우물 해금
  - 전체 이용 30명 → 국밥집 해금

- [ ] **해금 시 메뉴탭 표시 + 해우소 해금 연출**
  - 해우소 해금 시: 두루마기 모양 팝업 + "근심을 풀게되니 기쁘지 아니한가." 텍스트

- [ ] **직원 커버 범위 및 상한**
  - 무수리: 3×3 범위 내 뜸방 최대 2개 커버
  - 침구사: 3×3 범위 내 뜸방 최대 3개 커버
  - 의녀: 3×3 범위 내 침방 최대 3개 커버
  - 의관: 3×3 범위 내 약방 최대 2개 커버

- [ ] **직원 중복 커버 방지**
  - 침구사가 커버 중인 뜸방은 무수리 선택지에서 제외
  - 게이머가 수동 배정하는 구조
  - 커버할 방이 없으면 해당 직원은 배회 (에러 아님)
  - **알럿:** 침구사 배정으로 무수리 커버 가능 방이 0개가 될 경우 게이머에게 경고 팝업 표시

- [ ] **치료방 클릭 UI: 직원 투입/해제 탭**
  - 초과 커버 시 게이머가 방 직접 선택
  - 현재 커버 현황 시각적으로 표시

- [ ] **직원 없는 치료방 운영 불가**
  - 커버 직원 없는 치료방은 환자 입장 불가

- [ ] **우물 위치 보너스**
  - 약방 3×3 범위 내 우물 존재 시 해당 약방 이용 환자 +2전

- [ ] **시설 구매금액 · 수입**
  | 시설 | 구매가 | 환자 수입 |
  |------|--------|----------|
  | 마루 | 2전 | — |
  | 뜸방 | 30전 | 2전 |
  | 해우소 | 20전 | 1전 |
  | 침방 | 50전 | 3전 |
  | 약방 | 100전 | 6전 (진맥실 추가 시 8전) |
  | 국밥집 | 30전 | 3전 |

## Phase 4 — 만족도·티켓·계층 스폰

- [ ] **치료만족도 점수 계산**
  - 뜸방 +1 / 침방 +2 / 약방 +3
  - 소나무 인접(상하좌우) 시 ×1.2 (소수점 버림 처리)

- [ ] **편의시설 만족도 점수 계산**
  - 국밥 +2 / 우물 +1 / 해우소 +1

- [ ] **계층별 만족 판정 기준값**
  | 계층 | 치료만족 기준 | 편의만족 기준 |
  |------|------------|------------|
  | 노비 | 1점 이상 | 3점 이상 |
  | 농민 | 2점 이상 | 4점 이상 |
  | 상인 | 3점 이상 | 5점 이상 |
  | 선비 | 4점 이상 | 7점 이상 |
  | 양반 | 5점 이상 | 10점 이상 |

- [ ] **치료티켓 발행 확률**
  - 뜸 만족 → 40% 뜸티켓 +1 / 60% 침티켓 +1
  - 침 만족 → 70% 침티켓 +1 / 30% 약티켓 +1
  - 약 만족 → 70% 약티켓 +1 / 30% 약탕티켓 +1

- [ ] **티켓 개별 소멸 타이머**
  - 티켓 발행 시점부터 120초 경과 시 해당 티켓 개별 소멸

- [ ] **편의티켓 발행**
  - 편의시설 만족 시 같은 계층 편의티켓 +1

- [ ] **치료티켓 15장 → 가중치 스폰**
  - 노비 30% / 농민 20% / 상인 20% / 선비 20% / 양반 10% 중 1명
  - 스폰 후 티켓 15장 차감

- [ ] **편의티켓 15장 → 같은 계층 스폰**
  - 수요: 뜸 33% / 침 33% / 약 33% 무작위
  - 스폰 후 티켓 15장 차감

- [ ] **계층 해금 조건**
  - 치료 만족 노비 10명 → 농민 해금
  - 만족 농민 10명 → 상인 해금
  - 만족 상인 10명 → 선비 해금
  - 만족 선비 10명 → 양반 해금

## Phase 5 — 회계·명의 시스템

- [ ] **수입 즉시 적립**
  - 환자 시설 이용 완료 시 해당 금액 즉시 잔액 반영

- [ ] **월별 유지비·급료 자동 차감**
  - 치료방 유지비: 2전/월
  - 편의시설 유지비: 1전/월 (해우소·우물 제외)
  - 무수리 1전 / 침구사 2전 / 의녀 3전 / 의관 4전 (월급)

- [ ] **6개월 결산 팝업**
  - 총수입 - 유지비 - 급료 - 약재비 = 순이익
  - 그래프 형태로 표시 (상반기/하반기)

- [ ] **명의 수치 계산 및 UI 반영**
  - 변수명: `명의` 로 통일 (`명예` 아님)
  - 뜸 이용 +0.1 / 침 이용 +0.3 / 약 이용 +0.6
  - 뜸 만족 추가 +0.1 / 침 만족 추가 +0.3 / 약 만족 추가 +0.6

## Phase 6 — 조경·연출·UX 폴리시

- [ ] **소나무 배치**
  - 기본 3개 무료
  - 이후 추가 구매 가격 미정 (추후 스펙 추가 예정)

- [ ] **소나무 인접 보너스 및 제거 처리**
  - 뜸방·침방 상하좌우 인접 시 치료만족도 ×1.2
  - 소나무 제거 시 보너스 즉시 소멸

- [ ] **소나무 배치 시 인접 뜸방·침방 하트 연출**
  - 배치 시 인접 치료방 위에 0.5초간 하트 이펙트 표시 후 소멸

- [ ] **환자 계층·병 상태 UI 표시**
  - 신분 배지: 노비 / 농민 / 상인 / 선비 / 양반
  - 병 아이콘: 경증(뜸) / 중증(침) / 위중(약)

- [ ] **해우소 해금 두루마기 팝업 연출**

- [ ] **6개월 결산 그래프 시각화**

- [ ] **직원 커버 충돌 알럿**
  - 침구사 배정으로 무수리 커버 가능 방 0개 될 시 경고 팝업 표시
