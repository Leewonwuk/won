# 거인의 어깨 — 달아래약방 v0.6 평가 체크리스트

> 최우선 규약: 모든 Phase/Milestone 결과물은 아래 6거장 체크리스트(18항목)로 평가하며,
> 병렬 검증 에이전트 중 **"거인의 어깨 평가자"**는 이 문서를 기준으로 gap 리포트를 작성한다.
> v2 (2026-04-20): 도트 캐릭터 일러스트 검수용 **Pedro Medeiros** 추가 (6번째 거장, F. 항목).

## 승인된 6거장 (Option 1 확장형: 카이로 근간 + 픽셀 아트 이론가)

1. **Chris Sawyer** — 타이쿤 장르 확립자 (RollerCoaster Tycoon, Transport Tycoon)
2. **Peter Molyneux** — 경영 시뮬의 감정/신 놀이 (Theme Hospital, Dungeon Keeper, Populous)
3. **Will Wright** — 에뮬런트 시스템 설계의 거장 (SimCity, The Sims)
4. **Kairosoft (카이로소프트)** — 픽셀 도트 경영 시뮬의 UX 교과서 (게임발상국, 온천물어, 유원지물어) — **핵심 근간**
5. **Daniel Cook** — 게임 스킬 체인 / 코어 루프 이론가 (Lost Garden, "Skill Atoms")
6. **Pedro Medeiros** — 픽셀 아트 교육·이론가 (Celeste EXOK Games 아트, "Pixel Art Class" 교재) — **캐릭터 도트 검수 전담**

## 평가 체크리스트 (15항목)

### A. Chris Sawyer — 시뮬레이션 정밀성
- **[S1] 미세 단위 시뮬:** 손님/환자 하나하나가 개별 상태(만족도·대기·목적)로 움직이며, 플레이어가 그 개체를 관찰·추적 가능한가?
- **[S2] 경제 투명성:** 수입/지출 원천을 플레이어가 계층적으로 드릴다운 가능한가? (방별·환자별 수익 분해)
- **[S3] 건설 그리드 피드백:** 타일 설치/철거 시 즉시적·일관된 시각 피드백 + 경제 피드백(환급·비용)?

### B. Peter Molyneux — 감정 있는 경영
- **[M1] 성격 있는 NPC:** 환자 티어(노비/농민/상인/선비/양반)마다 대기·만족·지불 패턴이 구분되어 "저 사람은 저런 사람"으로 인식 가능?
- **[M2] 신(神)의 손 UX:** 직접 타일을 배치·철거하는 손맛 — 클릭/드래그/롱프레스의 즉시성과 유의미한 결과?
- **[M3] 서프라이즈 루프:** 예상치 못한 이벤트(도깨비·VIP·재료 이변)가 플레이어 선택을 압박하는 모멘트가 있는가?

### C. Will Wright — 에뮬런트 시스템
- **[W1] 창발적 배치:** 다양한 유효 배치(레이아웃)가 존재 — 정해진 정답 없이 플레이어의 공간 설계가 결과를 바꿈?
- **[W2] 시스템 간 상호작용:** 직원 커버리지, 방 인접성, 환자 경로가 서로 영향을 주어 단순 합 이상(예: 동선 단축 → 처리량↑ → 만족↑)?
- **[W3] 장기 성장 곡선:** 1일→1달→1년 스케일로 의미 있는 목표·리소스 변화(명의, 해금, 확장)가 누적되는가?

### D. Kairosoft — **픽셀 경영 시뮬 UX 근간**
- **[K1] 픽셀 가독성:** 16×20 / 64×64 도트가 축소된 800×720 캔버스에서도 각 환자·건물·상태가 한눈에 구별되는가? (색조 + 실루엣)
- **[K2] 주간/월간 결산 리듬:** 15초=1주, 1분=1달 사이클로 리포트·효과음·팝업이 리듬감 있게 끊어주는가?
- **[K3] 확장 해금 체감:** 신규 건물/환자/재료 해금이 "축하" 모멘트로 명확히 제시되고, 즉시 배치하고 싶게 만드는가?

### E. Daniel Cook — 스킬 아톰 / 코어 루프
- **[C1] 학습 스파이럴:** 첫 30초·3분·30분 각 구간에서 새로운 스킬·의사결정이 점진 도입되는가? (튜토리얼 없이도)
- **[C2] 피드백 3층:** 모든 행동이 즉시(0.2s)·단기(주간)·장기(월간) 피드백으로 보상 or 처벌되는가?
- **[C3] 의미 있는 선택:** 매 순간 2개 이상의 의미 있는 선택지(예: 마루 확장 vs 건물 업그레이드)가 공존하는가?

### F. Pedro Medeiros — 픽셀 아트 검수 (캐릭터 도트 일러스트 전담)
> 적용 시점: 새 캐릭터 스프라이트 도입 / 파이프라인 변경(예: `palette_transfer.py`) / Phase 7 렌더 리팩터 시점.
- **[P1] 실루엣 가독성:** 프레임 전체를 검정 실루엣으로 채워도 계층(노비·농민·상인·선비·양반)·성별·직업(무수리·의녀·침구·의관) 구분이 즉시 가능한가? 머리 형태·의상 실루엣·소품 3요소로 판독.
- **[P2] 한정 팔레트 일관성:** 각 캐릭터 **8~12색 이내**이며, 시트 전체에서 그림자·하이라이트·피부 톤이 공유 팔레트로 통일되는가? 그라데이션·AA 중간색 0건.
- **[P3] 1px 아웃라인 원칙:** 배경 타일(마루·뜸방 등) 위에서 캐릭터가 어두운 외곽선(1px)으로 분리되어 읽히는가? 카이로 **[K1]** 의 전제.
- **[P4] 발 정렬·수직 안정:** 걷기 12프레임에서 발 밑선 높이가 **±1px 이내**로 일정한가? (수직 흔들림·bob 효과는 별도 코드 tween 으로 구현, 원본 스프라이트는 발 기준선 고정)
- **[P5] 셀 경계 여백:** 스프라이트시트 각 프레임 **상하 최소 4px, 좌우 최소 2px** 여백. cell 경계에 캐릭터 픽셀이 닿으면 애니·축소 시 끊김. **AI 생성 의뢰 스펙 필수 포함 항목.**

## 사용 규약

- Phase 묶음(3개) 완료마다 **15항목을 점수화**하여 `[PASS / 조건부 / FAIL]`로 채점.
- 점수가 낮은 항목은 다음 묶음 우선순위에 편입.
- **병렬 에이전트 "거인의 어깨 평가자"**는 반드시 본 문서를 인용해 항목 ID(S1, M2, K3 등)로 gap을 지적해야 함.
- 거장/체크리스트 변경 시 사용자 승인 필수.
