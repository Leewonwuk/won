## 필수 출력 포맷

```
Sprite sheet layout : 3 columns × 4 rows (RPG Maker 포맷)
Rows (위→아래)      : 0=정면(Down), 1=좌측(Left), 2=우측(Right), 3=후면(Up)
Cols (좌→우)        : 0=left-step, 1=idle, 2=right-step
Total frames        : 12 (4방향 × 3프레임)
Canvas size         : 480 × 640 px (cell 160×160 권장) 또는 192×256 (cell 64×64)
                      ※ AI 가 고해상도로 그린 뒤 파이프라인이 NEAREST 로 64×64 다운스케일
```

## Pedro 체크리스트 준수 (프롬프트 필수 포함)

### [P1] 실루엣 가독성
- 한복 상하의 + 직업 소품 (항아리·빗자루·갓·봇짐 등) 으로 역할 판독 가능해야 함.
- 검정 실루엣으로 채워도 계층·성별·직업 구분 가능해야 함.

### [P2] 한정 팔레트 (8~12색, AA 금지)
- **의녀 팔레트를 글로벌 시드로 공유**:
  ```
  #000000  (아웃라인/검정)
  #47413b  (그림자/갈회색)
  #eedde4  (피부 밝음)
  #f9cba1  (피부 기본)
  #d28844  (피부 그림자)
  #f6ad6b  (밝은 황토)
  #b09fa6  (연보라 회색)
  #f785b7  (분홍 하이라이트)
  #d64766  (빨강 저고리)
  #9d0a0a  (진빨강 그림자)
  #1132b0  (파랑 치마)
  #051a69  (진파랑 그림자)
  ```
- 위 12색 중 **아웃라인(#000000) + 피부 3색 + 그림자(#47413b)** 는 전 캐릭터 공유 고정.
- 의상 색은 계층별로 교체 가능하지만 **동일 hue 의 명도 2단계 (기본+그림자)** 원칙 준수.
- **anti-aliasing, 중간 그라디언트, 블러 금지**. 모든 색 경계는 하드 엣지.

### [P3] 1px 아웃라인
- 캐릭터 외곽 전체 1px `#000000` 아웃라인.
- 내부 디테일 (머리카락-얼굴, 팔-몸통 경계 등) 도 1px `#000000` 또는 `#47413b`.
- 2px 이상 두께 아웃라인 금지. 아웃라인 끊김/뭉침 금지.

### [P4] 발 정렬·수직 안정
- 12 프레임 모두 발 밑선 Y 좌표 **±1px 이내**로 일정.
- 걷기 모션은 팔·다리·머리 흔들림만 표현. 몸 전체 Y 이동 (bob) 은 **금지** — 게임 코드에서 tween 으로 별도 처리.
- 각 row 3프레임 모두 동일 발 위치여야 함 (가운데 idle = 양발 수평, left-step/right-step = 한발 들림).

### [P5] 셀 경계 여백 ⚠️ **원본 데이터 결함의 직접 원인**
- **각 셀 내부에서 상하 최소 20px, 좌우 최소 10px 여백** (160×160 cell 기준).
- 캐릭터 픽셀이 셀 경계선에 **절대** 닿지 않아야 함.
- 머리카락 끝, 치마 아래 끝, 팔 끝, 소품 (지팡이·갓) 모두 포함.
- 치마가 길어서 안 맞으면 치마 길이를 줄일 것. 셀을 넘기지 말 것.
- 배경: 완전 투명 `alpha=0` 또는 마젠타 `#FF00FF` 크로마키 단색.
- **격자선·셀 구분선·가이드 라인 금지** — 순수 투명 배경에 캐릭터만.
